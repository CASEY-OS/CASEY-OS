# Casey Rose

**AI agent reliability: guardrails, evals and AI operations.**

I build the checks that catch AI coding agent failures before they reach people, and I publish how well they work, misses included.

- **[agent-guard-bench](https://github.com/CASEY-OS/agent-guard-bench)**: an open benchmark of my guard for Claude Code. Sealed blind test sets written by outside AI models after the guard froze, a small-model baseline scored on the same set, and every miss and false block listed. Run it with `python3 bench.py`.
- **[Veteran Benefits GPS](https://vbgps.org)**: a free, navigation-only guide that sends Veterans and their families to the right official VA.gov starting point. Public since Veterans Day, November 11, 2026.
- **CASEY_OS** (private): the multi-agent system on Claude Code that runs my company's real work, with an error ledger, written rules and a human yes before anything leaves.

Claude Code agents write most of the code under my direction; I design the checks, the tests and the pass rules, and I make the scoring calls.

U.S. Army Veteran (Kentucky Army National Guard, military police, Operation New Dawn). Former teacher and coach. Harrisburg, Illinois.
